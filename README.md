# Telegram Username Checker

Бот для проверки занятости Telegram юзернеймов.

## Возможности

- ✅ Проверка неограниченного количества юзернеймов
- ✅ Прогресс-индикатор в реальном времени
- ✅ Проверка базовых имен и вариантов с суффиксами `bot` и `_bot`
- ✅ Разделение свободных и занятых имен

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python bot.py
```

## Использование

1. Найдите бота в Telegram
2. Отправьте `/start`
3. Отправьте список юзернеймов:
   ```
   test1 test2 test3
   ```
